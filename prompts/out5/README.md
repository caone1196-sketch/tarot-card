# prompts/out5

Bộ prompt đã biên tập lại từ bộ prompt gốc để tạo **artwork-only**:

- Không khung viền.
- Không đường viền vàng.
- Không tên lá.
- Không chữ hoặc số.
- Không emblem, icon, symbol, medallion hoặc ribbon.
- Cảnh phủ kín canvas `784 × 1360`, tỷ lệ `7:12`.
- Giữ nguyên mô tả cảnh, nhân vật, COUNT LOCK và ANATOMY LOCK từ prompt gốc.
